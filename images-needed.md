# Images

The site ships with **no raster images**. The hero artwork (an animated tree-ring cross-section), the logo mark
and the favicon are inline SVG generated by `scripts/make-art.js`, so nothing is missing and no `<img>` tag
points at a placeholder.

If you later want real photos, these are the slots that would benefit most. Drop the files into
`src/assets/img/` with these exact names and add an `<img>` where noted.
